# Fishing icon pack

Thirteen independent transparent PNGs, 512 × 512, created with the built-in image generation tool in a cohesive 16-bit farming RPG pixel style.

| File | Stable asset ID | Subject / purpose |
| --- | --- | --- |
| trout.png | fishing-v2-trout | Rainbow trout |
| crayfish.png | fishing-v2-crayfish | Freshwater crayfish |
| eel.png | fishing-v2-eel | River eel |
| catfish.png | fishing-v2-catfish | Catfish |
| sturgeon.png | fishing-v2-sturgeon | Sturgeon |
| tuna.png | fishing-v2-tuna | Bluefin tuna |
| oyster.png | fishing-v2-oyster | Open pearl oyster |
| jelly.png | fishing-v2-jelly | Jellyfish |
| swordfish.png | fishing-v2-swordfish | Swordfish |
| whaleshark.png | fishing-v2-whaleshark | Whale shark |
| k_lake.png | fishing-v2-k_lake | Legendary golden carp, king of the lake |
| k_river.png | fishing-v2-k_river | Legendary emerald dragon fish, king of the river |
| k_sea.png | fishing-v2-k_sea | Legendary deep-sea king with trident crown |

These are standalone assets, not sprite-sheet crops. Original high-resolution images are retained under `.art-originals/fishing-v2/`. Exact descriptions, generation prompts and source paths are recorded in `fishing-art-jobs.json` in the project root. A visual gallery is available at `previews/fishing-v2.html` and `previews/fishing-v2.png`.

This pack does not replace current game registries or modify gameplay, balance, or save data. When integrating, map each exact filename to its corresponding fish key in the live art registry; do not rebuild the game from old templates. Use `image-rendering: pixelated` for scaled pixel-art presentation.
